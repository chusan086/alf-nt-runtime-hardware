# 流式接口

发布的三个顶层均使用一条 32 位 ready/valid 请求通道和一条 32 位 ready/valid
响应通道：

| 信号 | 方向 | 含义 |
|---|---:|---|
| `clk_i` | 输入 | 上升沿时钟 |
| `rst_ni` | 输入 | 低有效复位 |
| `req_valid_i` | 输入 | 请求字有效 |
| `req_ready_o` | 输出 | 与 valid 同时为高时接收请求字 |
| `req_data_i[31:0]` | 输入 | 请求字 |
| `rsp_valid_o` | 输出 | 响应字有效 |
| `rsp_ready_i` | 输入 | 与 valid 同时为高时接收响应字 |
| `rsp_data_o[31:0]` | 输出 | 响应字 |

共享核顶层为 `n12_alf_shared_top`。两个固定核目录均使用
`n12_alf_matched_fixed_v3_top`，编译时只能选择其中一个固定核目录。

共享核及发布的 M1/M4 固定核均接收 20 个低位字在先的请求字：

| 字序号 | 字段 |
|---:|---|
| 0--3 | 128 位密钥，最低有效字在先 |
| 4--5 | 64 位应用/上下文标识 |
| 6--9 | 128 位微调值（tweak） |
| 10--13 | 128 位 `Q` |
| 14 | 配置：`n[3:0]`、`t[6:4]`、解密位 7、循环游走位 8、驻留上下文复用位 9；31:10 位必须为零 |
| 15--18 | 128 位输入 |
| 19 | 命令，当前取值为 `1` |

响应共五个字：四个 32 位结果字，随后是一个状态字。只有 valid 与 ready 同时为高
时才发生一次字传输；前一操作或响应尚未结束时，不接收新的请求输入。

状态 `0` 表示请求成功完成；状态 `1` 表示请求被拒绝或因错误终止，此时四个结果
字全部为零。每个请求都要求命令字 19 等于 `1`、配置保留位 31:10 为零，且
128 位输入小于 `Q`。共享核还会检查文档规定的 `(n,t,Q)` 合法域。为保持匹配
比较，发布的 M1/M4 固定核保留 20 字传输格式，并要求传入的 `Q`、`n`、`t`
严格等于相应固定实例的常量。
