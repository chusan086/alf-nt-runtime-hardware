# 架构说明

共享核通过一条 32 位 ready/valid 请求流接收一次完整操作，并返回五个 32 位响应字。
运行时参数只验证一次，随后转换为寄存的操作描述符，供局部控制器、密钥/微调值、
轮运算和轮密钥存储服务使用。各操作阶段以时分方式复用同一条 AES 轮运算通路。

最终 FPGA 轮密钥存储采用推断的同步 RAM。M1 和 M4 保留与共享核相同的 AES
轮通路、控制器/服务边界、轮密钥存储接口、复位语义和流式协议，仅将运行时参数
选择替换为一个静态参数点。这构成本文接受的同源比较边界。

本发布的结论仅限 ALF-n-t 算法族，不声称该架构是适用于无关密码族的通用共享
硬件方法。
